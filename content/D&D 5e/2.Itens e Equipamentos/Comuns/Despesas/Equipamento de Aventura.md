# Equipamento de Aventura *(Adventuring Gear)*

Esta seção apresenta as regras para equipamentos de aventura, detalhando como os personagens podem fabricar e utilizar itens, bem como o impacto desses objetos na jogabilidade.

**Criação de Itens**

*   Os personagens podem fabricar itens utilizando a habilidade de Item Creation (Criação de Itens).
*   A Difficulty Class (Classe de Dificuldade) para criar um item é determinada pelo seu atributo base.
*   O tempo exigido para a fabricação é proporcional ao número de minutos de trabalho que o personagem dedica à tarefa.

**Uso de Itens**

*   Os personagens podem utilizar itens fabricados por meio da ação de Use an Object (Usar um Objeto).
*   A Difficulty Class (Classe de Dificuldade) para ativar ou utilizar um item é determinada pelo seu atributo base.
*   O tempo necessário para a utilização é proporcional ao número de minutos que o personagem tem disponível para interagir com o objeto.

**Itens Especiais**

*   Alguns itens possuem efeitos especiais, como conceder bônus em Ability Checks (Testes de Habilidade) ou permitir que o personagem utilize habilidades adicionais.
*   Tais efeitos são detalhados na descrição do item.

**Destruição de Itens**

*   Os personagens podem destruir itens utilizando a ação de Destroy Item (Destruir Item).
*   A Difficulty Class (Classe de Dificuldade) para destruir um item é determinada pelo seu atributo base.
*   O tempo necessário para a destruição é proporcional ao número de minutos que o personagem tem disponível para executar a ação.

Estas são as regras fundamentais para a criação e o uso de itens no jogo. Lembre-se de que cada item pode possuir propriedades e efeitos únicos; portanto, leia atentamente a descrição do objeto antes de utilizá-lo em suas aventuras.
