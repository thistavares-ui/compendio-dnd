# Ferramentas de Comunicação para Surdos *(Deaf Communication Tools)*

**Fonte:** D&D Wiki  
**Tipo:** Ferramenta  
**Dano:** —  
**Propriedades:** —  

Este conjunto de ferramentas foi projetado para facilitar a comunicação silenciosa entre criaturas, especialmente aquelas que são surdas ou que precisam operar sem emitir sons. Possuir habilidade com este kit permite que você leia os lábios de uma criatura, desde que esteja dentro de seu campo de visão e que ela esteja falando em um idioma que você compreenda.

O conjunto inclui:  
- Um caderno em branco com 300 páginas.  
- Três canetas de tinta permanente.  
- Um manual ilustrado de sinais de combate, com símbolos padronizados para comunicação tática em campo.  
- Uma pequena bolsa de couro contendo figuras de madeira esculpidas (como um arqueiro, um dragão ou um mago), usadas para representar unidades, estratégias ou conceitos abstratos em situações onde a linguagem de sinais é insuficiente.

**Custo:** 20 po  
**Peso:** 2,5 kg (5 lb)  

*Observação:* A habilidade com este kit conta como uma ferramenta de especialização. Ao usar as figuras de madeira, você pode realizar uma *Action (Ação)* para representar uma mensagem complexa, substituindo uma tentativa de comunicação verbal — útil em ambientes silenciosos, como emboscadas ou locais mágicos onde o som é suprimido.
