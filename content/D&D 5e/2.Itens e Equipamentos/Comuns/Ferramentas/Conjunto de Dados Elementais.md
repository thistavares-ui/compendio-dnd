# Conjunto de Dados Elementais *(Set of Elemental Dice)*

**Fonte:** D&D Wiki  
**Tipo:** Ferramentas  
**Dano:** —  
**Propriedades:** —  

Um conjunto de cinco dados de dez lados, cada um gravado com um símbolo elemental distinto. Esses dados são amplamente utilizados em jogos de azar, rituais de adivinhação e competições acadêmicas entre magos, adivinhos e estudantes de magia. Sua popularidade é imensa em academias mágicas, onde conjuntos básicos são oferecidos como presentes a novos alunos, enquanto versões artesanais, encrustadas com metais preciosos ou runas místicas, são concedidas como prêmios por conquistas notáveis.  

Do outro lado da sociedade, jogadores de cassinos clandestinos e trapaceiros os adoram por sua natureza abstrata e universal — os símbolos não são facilmente associáveis a valores numéricos, permitindo que sejam usados disfarçadamente em golpes de engano, trocas fraudulentas e apostas ilícitas.  

O conjunto padrão contém símbolos representando os dez tipos de dano mágico primário, embora variações existam com runas antigas, letras arcanas ou ícones culturais regionais.

## Jogos com Dados Elementais: Kerimbo

O jogo de azar conhecido como **Kerimbo** deriva seu nome de uma gíria de ladrões antigos, mas sua popularidade transformou a linguagem — termos originais foram substituídos para evitar detecção. Os jogadores acumulam pontos ao alinhar os símbolos dos dados em categorias específicas, buscando combinações que se complementem ou se anulem mutuamente. Cada símbolo tem uma relação de afinidade com outro, formando pares estratégicos.

O Kerimbo possui inúmeras variações regionais, com regras que mudam conforme a cultura, a escola ou até o bar onde é jogado. Trapaceiros exploram essa flexibilidade, alterando as regras durante a partida e alegando que o oponente “esqueceu” a versão local. Com o tempo, algumas regras se estabilizaram, mas variantes ainda florescem — é comum que vilas, cidades e academias tenham suas próprias categorias de pontuação.

### Como Jogar Kerimbo

Em sua vez, cada jogador lança os cinco dados elementais uma vez e pode re-rolar até dois dos dados, em até duas rodadas de re-lançamento. Após isso, o jogador escolhe **uma única categoria de pontuação** para aplicar sua rolagem — mesmo que ela não lhe traga pontos. O jogo é jogado por até quatro jogadores, e termina quando todas as categorias forem preenchidas por todos. O vencedor é aquele com mais pontos acumulados.

| A Luz          | Todos os dados devem ser **Radiante**, **Elétrico**, **Fogo**, **Força** ou **Ácido**. **Inválido** se menos de 3 tipos forem representados. | 15 pontos        |
| O Escuro       | Todos os dados devem ser **Necrótico**, **Trovejante**, **Frio**, **Psíquico** ou **Venenoso**. **Inválido** se menos de 3 tipos forem representados. | 15 pontos        |
| Generalização  | 5 dados de qualquer tipo. Cada dado que não se encaixa em outra categoria vale 5 pontos.                               | 25 pontos        |

## Jogos de Lançamento Mágico

Jogos de dados elementais também são usados por magos como ferramentas de decisão mágica — ou, menos oficialmente, como apostas de alta stakes. Três versões são amplamente reconhecidas nas academias e entre os feiticeiros errantes: **Eliminação**, **Buraco** e **Duelo**.

### Eliminação

Até 10 jogadores participam. Dois dados são lançados simultaneamente. O elemento cujo símbolo é **inferior** em hierarquia é eliminado. Se mais de dois jogadores estiverem envolvidos, o jogador que lançou o dado perdedor é eliminado da rodada. Empates ou elementos eliminados resultam em re-lançamento. O jogo continua até que apenas um elemento permaneça. Cada elemento pode ter um valor atribuído (ex: “Fogo = 50 gp”), tornando o jogo uma forma de sorteio mágico ou aposta de alto risco.

### Buraco

Jogado por 2 a 5 jogadores. Cada jogador lança seus cinco dados simultaneamente (ou em sequência, com anotação das rolagens anteriores). Em seguida, compara-se cada dado de um jogador contra cada dado do oponente, contabilizando vitórias e derrotas. Um dado vence outro conforme a tabela de hierarquia abaixo. O jogador com mais vitórias (ou menos derrotas) vence. Empates são decididos por um re-lançamento único entre os jogadores empatados.

### Duelo

A versão mais simples e rápida. Dois jogadores lançam um único dado cada. O vencedor é determinado pela hierarquia de elementos (veja tabela abaixo). Pode ser jogado em séries de até cinco rodadas, permitindo que mais de dois jogadores participem em turnos alternados.

## Hierarquia Padrão dos Elementos *(Jogos de Lançamento Mágico)*

> **Nota:** A hierarquia define qual elemento vence outro em confronto direto. Vence quem está acima na lista. Empates ocorrem entre elementos iguais.

| Elemento      | Vence contra                                                                 |
|---------------|------------------------------------------------------------------------------|
| Ácido         | Frio, Fogo, Água, Neve, Punho, Raio, Crânio, Folha, Olho, Sol, Sininho       |
| Frio          | Fogo, Força, Elétrico, Necrótico, Venenoso, Psíquico, Radiante, Trovejante   |
| Fogo          | Força, Elétrico, Necrótico, Venenoso, Psíquico, Radiante, Trovejante, Água   |
| Força         | Elétrico, Necrótico, Venenoso, Psíquico, Radiante, Trovejante, Água, Neve    |
| Elétrico      | Necrótico, Venenoso, Psíquico, Radiante, Trovejante, Água, Neve, Punho       |
| Necrótico     | Venenoso, Psíquico, Radiante, Trovejante, Água, Neve, Punho, Raio            |
| Venenoso      | Psíquico, Radiante, Trovejante, Água, Neve, Punho, Raio, Crânio              |
| Psíquico      | Radiante, Trovejante, Água, Neve, Punho, Raio, Crânio, Folha                 |
| Radiante      | Trovejante, Água, Neve, Punho, Raio, Crânio, Folha, Olho                     |
| Trovejante    | Água, Neve, Punho, Raio, Crânio, Folha, Olho, Sol                            |
| Água          | Neve, Punho, Raio, Crânio, Folha, Olho, Sol, Sininho                         |
| Neve          | Punho, Raio, Crânio, Folha, Olho, Sol, Sininho                               |
| Punho         | Raio, Crânio, Folha, Olho, Sol, Sininho                                      |
| Raio          | Crânio, Folha, Olho, Sol, Sininho                                            |
| Crânio        | Folha, Olho, Sol, Sininho                                                    |
| Folha         | Olho, Sol, Sininho                                                           |
| Olho          | Sol, Sininho                                                                 |
| Sol           | Sininho                                                                      |
| Sininho       | — (nunca vence)                                                              |

> **Observação:** Esta hierarquia é **cíclica e não linear**. Embora pareça uma escala ascendente, na prática, cada elemento vence os que estão abaixo dele na lista, e perde para os que estão acima. O “Sininho” é o mais fraco — sempre perde, exceto em empates.
