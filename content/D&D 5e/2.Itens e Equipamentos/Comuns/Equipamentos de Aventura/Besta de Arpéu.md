# Besta de Arpéu *(Grappling Hookshot)*

**Fonte:** D&D Wiki
**Tipo:** Equipamento de Aventura
**Dano:** 1d6 + 1 + modificadores Perfurante (Piercing) (a partir de 12,5 m causa apenas 1d4 + 1 + modificadores)
**Propriedades:** Munição (Ammunition), Recarga (Loading), Duas Mãos (Two-Handed)

A Besta de Arpéu é uma Besta Leve (Light Crossbow) modificada, equipada com um guincho manual e 30 metros de corda. O projétil foi adaptado para funcionar como um arpéu, permitindo agarrar e escalar certos alvos — geralmente superfícies macias o suficiente para serem perfuradas ou saliências resistentes o bastante para suportar o gancho. Este equipamento é considerado um item Incomum (Uncommon), mas pode ser fabricado por qualquer armeiro habilidoso, desde que os componentes estejam disponíveis; caso contrário, será necessária a perícia de um mestre armeiro élfico.

A Besta de Arpéu possui alcance de 12/30 metros. Se o alvo atingido for mais leve que o usuário, este deve realizar um teste de Força (Strength check) para tentar puxar o alvo até 6 metros para mais perto.
