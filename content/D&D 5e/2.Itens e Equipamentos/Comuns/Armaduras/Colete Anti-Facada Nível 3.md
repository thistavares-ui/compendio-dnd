# Colete Anti-Facada Nível 3 *(Stab Vest, Level 3 Spikes)*

**Fonte:** D&D Wiki
**Tipo:** Armadura Leve (Light Armor)
**Dano:** —
**Propriedades:** —

Este colete reforçado com placas metálicas atua como uma mola, empregando uma malha de materiais elásticos para absorver e dispersar a energia dos impactos. Trata-se de uma armadura corporal projetada especificamente para deter ataques de armas brancas improvisadas em combate corpo a corpo (Melee). A classificação Nível 3 foi desenvolvida para suportar golpes de alta velocidade desferidos por armas pesadas, sendo um equipamento padrão entre os agentes penitenciários de presídios de segurança máxima.

**Peso:** 4,5 kg
