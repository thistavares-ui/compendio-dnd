# Broquel de Couro *(Leather Buckler)*

**Fonte:** D&D Wiki
**Tipo:** Arma Defensiva
**Dano:** 1d6 Perfurante
**Propriedades:** 

O broquel de couro é um pequeno escudo feito de couro reforçado, dotado de uma borda metálica e fixado diretamente ao antebraço, o que deixa a mão livre para segurar outro item. Este escudo concede ao usuário +1 de Armor Class (Classe de Armadura). Se você for proficiente com escudos, pode realizar um ataque com este broquel, causando 1d6 de dano perfurante. No entanto, se utilizar essa mão para realizar qualquer outra tarefa como parte de uma Action (Ação) ou Bonus Action (Ação Bônus), você perde o bônus na Armor Class (Classe de Armadura) até o início do seu próximo turno.

**Peso:** 3 kg
