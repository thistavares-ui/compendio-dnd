# Colete Anti-Laceração Nível 3 *(Level 3 Slash-Resistant Vest)*
**Fonte:** D&D Wiki
**Tipo:** Armadura
**Dano:** —
**Propriedades:** —

Este colete funciona como uma mola, utilizando uma trama de materiais elásticos para amortecer e dispersar a energia dos impactos. Projetado especificamente para neutralizar ameaças de armas brancas modernas, como facas e machetes, esta armadura corporal oferece proteção excepcional contra cortes e lacerações. A variante Nível 3 é engenhosamente calibrada para absorver golpes de alta velocidade desferidos por armas pesadas. Trata-se do equipamento mais robusto e volumoso disponível no mercado para mitigar o impacto de armamentos pesados de corte.
