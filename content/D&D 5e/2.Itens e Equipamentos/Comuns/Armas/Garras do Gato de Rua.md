# Garras do Gato de Rua *(Alley Cat Fangs)*

**Fonte:** D&D Wiki
**Tipo:** Arma Marcial Corpo-a-Corpo
**Dano:**

As Garras do Gato de Rua são duas facas curvas, cada uma com uma faixa laranja no canto da lâmina. Cada cabo é envolto em um tecido azul e possui um anel circular na parte posterior. O tecido ao redor do cabo e pendurado no anel brilha com uma cor laranja intensa quando segurado firmemente. Quando você se sintoniza com essas facas, você se sintoniza com ambas como se fossem um item mágico único.

Quando você possui ambas as facas consigo, você tem um bônus de +1 nos rolos de ataque e dano feitos com qualquer uma delas. Você pode usar qualquer uma das seguintes propriedades mesmo que tenha apenas uma das facas consigo:

**Bote.**
Se você atacar uma criatura surpresa usando qualquer uma dessas facas, o ataque causa 2d4 de dano perfurante adicional.

**Olhos do Gato.**
Enquanto segura ambas as facas, você possui visão no escuro até uma distância de 18 metros. Enquanto segura apenas uma delas, essa distância é reduzida para 9 metros.

**Graça do Gato.**
Enquanto segura uma das facas, você pode usar sua ação para lançar a magia **Aprimorar Atributo**, mas pode escolher apenas o efeito **Graça do Gato** e apenas pode ser o alvo. Você pode lançar essa magia uma vez por cada faca. Uma vez que a magia seja lançada usando uma faca, ela não pode ser lançada novamente usando essa faca até o amanhecer seguinte.

**Retorno Mágico.**
Depois que você usa sua ação para jogar uma das facas, você pode usar sua **Ação Bônus** para teleportar a faca de volta para sua mão livre. Para fazer isso, é necessário fazer um gesto somático com essa mão.
