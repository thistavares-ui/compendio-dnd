# Rifle Não Linear Grindell/Galileano M6 *(M6 Grindell/Galilean Nonlinear Rifle)*

**Fonte:** D&D Wiki  
**Tipo:** Arma Marcial à Distância (Martial Ranged Weapon)  
**Dano:** 10d10 Radiante (Radiant)  
**Propriedades (Properties):** Pesada (Heavy), Munição (Ammunition) [alcance (range) 150/200 m (500/600 ft)], 4 disparos.

O Rifle Não Linear Grindell/Galileano M6 é uma arma de energia de alta potência, projetada exclusivamente para uso pelos Spartans da UNSC. Ela opera consumindo uma bateria de plasma interna. Esta bateria é incompatível com qualquer outra arma baseada em plasma e custa o dobro do preço normal de reposição. Esta arma não pode ser escolhida como equipamento inicial (starting equipment).

A arma foi projetada para os Spartans e requer um valor de atributo de Força (Strength) 18 ou o uso de uma armadura de poder (power armor), como a Mjolnir Mk. V, para ser manuseada corretamente. Caso o usuário não atenda a esses requisitos, ele sofre desvantagem (disadvantage) em todas as suas jogadas de ataque (attack rolls) realizadas com esta arma.

Para disparar, o usuário deve primeiro carregar (charge) a arma usando uma ação (action). Se o usuário não gastar sua próxima ação para realizar um ataque, a arma perderá a carga acumulada. Após um disparo, o usuário deve gastar uma ação (action) para ventilar a arma (vent the weapon) antes de poder carregá-la novamente.

Esta arma pesa 20 kg (44 lb) e possui capacidade para apenas 4 disparos.
