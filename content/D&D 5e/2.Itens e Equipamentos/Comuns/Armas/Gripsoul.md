# Gripsoul *(Gripsoul)*

**Fonte:** D&D Wiki
**Tipo:** Arma Marcial Corpo-a-Corpo
**Dano:** 1d10 + Força (com vantagem)
**Propriedades:**

Uma antiga espada longa. Quando um inimigo é morto com esta arma, o usuário pode optar por capturar sua essência dentro de uma série de gemas montadas no pomo. Essa essência pode ser liberada durante um Descanso Longo. Apenas quatro essências podem ser mantidas dentro do Gripsoul simultaneamente.

Diferentes tipos de criaturas conferem diferentes efeitos:

* Aberração: o usuário torna-se resistente a dano Psíquico e Energético
* Bicho: adiciona 1d6 de dano extra contra humanóides
* Celestial: adiciona 1d4 de dano Radiante extra e permite que o usuário lance a magia *Curar Ferimentos* como se fosse um espaço de magia de 3º nível uma vez, recuperando o uso ao amanhecer
* Dragão: adiciona 1d6 de dano Elemental baseado no tipo de dano original do dragão
* Elemental: adiciona 1d6 de dano baseado no tipo do elemento
* Fada: permite que o usuário se encolha como se estivesse usando a magia *Aumentar/Reduzir*
* Gigante: permite que o usuário cresça como se estivesse usando a magia *Aumentar/Reduzir*
* Humanóide: adiciona 1d6 de dano extra contra não-humanóides
* Monstruosidade: o usuário pode lançar a magia *Medo* duas vezes, recuperando os usos após uma hora
* Gosma: adiciona 1d6 de dano Venenoso e faz que golpes contra inimigos enferrujem metal
* Planta: o usuário pode invocar raízes para restringir inimigos como se estivesse lançando a magia *Enredar* duas vezes, recuperando os usos após uma hora
* Zangão: permite que o usuário ocupe o espaço de outra criatura independentemente do tamanho
* Morto-vivo: adiciona 1d4 de dano Necrótico e cura o usuário pela metade do dano causado
