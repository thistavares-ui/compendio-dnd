# Flindbar *(Flindbar)*

**Fonte:** D&D Wiki  
**Tipo:** Arma Marcial Corpo-a-Corpo  
**Dano:** 2d4 de dano contundente  
**Propriedades:** Se você é proficiente com armas marciais, você pode usar uma ação para tentar enredar uma criatura adjacente usando o flindbar. A criatura pode realizar um teste de Força (CD 8 + seu bônus de proficiência + seu modificador de Força) para resistir. Se falhar, ela estará enredada até o início do seu próximo turno.

O flindbar é uma barra de ferro pesada conectada por correntes, originalmente criada pelos flinds — criaturas parentes dos gnolls. Este instrumento brutal é especialmente útil em combate para imobilizar inimigos em proximidade.  

**Peso:** 1 kg
