# Arma da Mudança *(Weapon of Change)*

**Fonte:** D&D Wiki
**Tipo:** [[D&D 5e/1.Regras/1.1.Compêndio/1.1.8.Magias/Nível 2/Arma Mágica]] (Rara)

Esta arma brilha com uma luz intensa e parece ser feita de nuvens. Seu toque é suave e liso, mas macio como um travesseiro. Quando empunhada para o combate, ela se solidifica em uma arma normal.

**Cargas.** Esta arma mágica possui 7 cargas e recupera 1d6 + 1 cargas gastas diariamente ao amanhecer.

**Mudança de Forma.** Enquanto segura esta arma, você pode usar uma ação para gastar uma ou mais de suas cargas para transformá-la em outra espécie de arma. O número de cargas que você gasta é baseado nas Propriedades da arma desejada, conforme a tabela abaixo. Se a arma tiver mais de uma propriedade, você gasta cargas com base na propriedade mais cara.

| Propriedade | Cargas Requeridas |
| --- | --- |
| Munição | 2 |
| Acuidade | 2 |
| Pesada | 3 |
| Leve | 1 |
| Recarga | 4 |
| Alcance | 5 |
| Versátil | 3 |
| Arremesso | 3 |
| Duas Mãos | 5 |

**Nuvem de Adagas.** Enquanto segura esta arma, você pode usar uma ação e gastar uma carga para lançar o feitiço Nuvem de Adagas (*Blade Ward*) com uma DC de Teste de Resistência (Saving Throw) de 15.
