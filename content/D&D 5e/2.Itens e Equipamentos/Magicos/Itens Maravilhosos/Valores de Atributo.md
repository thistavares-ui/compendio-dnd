# Valores de Atributo *(Ability Scores)*

**Fonte:** D&D Wiki  
**Tipo:** Item Mágico  
**Dano:**  
**Propriedades:**  

Os valores de atributo definem as qualidades físicas e mentais de uma criatura, incluindo sua força, destreza, constituição, inteligência, sabedoria e carisma. Eles são usados para determinar a capacidade da criatura em realizar diferentes tarefas.

Cada habilidade tem um valor que define sua magnitude, conhecido como Bônus de Atributo. Um Bônus de atributo não é apenas uma medida das capacidades inatas de uma criatura, mas também inclui seu treinamento e competência em atividades relacionadas àquela habilidade.

A tabela abaixo mostra os Bônus de Atributo para diferentes valores de Bravura:

| Bravura | Bônus |
| --- | --- |
| 1 | −5 |
| 2–3 | −4 |
| 4–5 | −3 |
| 6–7 | −2 |
| 8–9 | −1 |
| 10–11 | +0 |
| 12–13 | +1 |
| 14–15 | +2 |
| 16–17 | +3 |
| 18–19 | +4 |
| 20–21 | +5 |
| 22–23 | +6 |
| 24–25 | +7 |
| 26–27 | +8 |
| 28–29 | +9 |
| 30 | +10 |

Para determinar um Bônus de Atributo sem consultar a tabela, subtraia 10 da Bravura de Atributo e divida o total por 2 (Arredondar para Baixo).

Os Bônus de Atributo afetam quase todas as jogadas de ataque, testes de atributo e salvaguardas, tornando-os mais frequentes no jogo.
