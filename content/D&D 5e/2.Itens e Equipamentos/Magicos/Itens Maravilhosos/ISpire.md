# ISpire *(ISpire)*

**Fonte:** D&D Wiki  
**Tipo:** Item Maravilhoso  
**Dano:** -  
**Propriedades:**

A ISpire é um item mágico que pode armazenar música para ser ouvida mais tarde. O item tem as seguintes propriedades:

* **Criar Playlist**: Enquanto estiver segurando este item, você pode usar uma ação para gastar um uso de Inspiração de Bardo (Bardic Inspiration) e adicionar 1 carga a este item. O número máximo de cargas do item é igual a 5 vezes o seu bônus de proficiência, e ele começa com 0 cargas quando você se sintoniza com ele.
* **Reproduzir**: Enquanto estiver tocando em este item, qualquer criatura pode usar uma ação para gastar uma carga dele e ganhar um dado de Inspiração de Bardo (Bardic Inspiration). O tamanho do dado é igual ao tamanho do dado de Inspiração de Bardo (Bardic Inspiration) do Bardo que está sintonizado com este item. Uma criatura pode ter apenas um dado de Inspiração de Bardo (Bardic Inspiration) em seu poder a cada vez.
* **Sistema de Fala**: Enquanto estiver sintonizado com este item, o seu número máximo de usos de Inspiração de Bardo (Bardic Inspiration) é aumentado pelo seu bônus de proficiência. Quando uma criatura rola um número menor que o seu bônus de proficiência em um dos seus dados de Inspiração de Bardo (Bardic Inspiration), ela pode tratar a rolagem como igual ao bônus de proficiência.
