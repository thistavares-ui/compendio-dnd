# Sortudo *(Lucky)* *(Sortudo)*

## Sortudo (Lucky)

O sistema *Sortudo* em Dungeons & Dragons (D&D) é um mecanismo que gera eventos ou recompensas aleatórios quando uma condição específica é atendida. A tabela a seguir lista diversos resultados, cada um associado a uma chance específica de ocorrência (rolagem de d20).

### Tabela: Sortudo

| Rolagem | Resultado |
|---------|-----------|
| 1       | Você ganha uma recompensa mágica inesperada. |
| 2       | Um objeto valioso cai do céu e cai aos seus pés. |
| 3       | Você é abençoado com uma sorte extraordinária por 24 horas. |
| 4-5     | Você encontra um tesouro escondido em um local inusitado. |
| 6-7     | Um animal selvagem se aproxima de você, curioso. |
| 8-9     | Você descobre um mapa antigo que aponta para um local secreto. |
| 10-11   | Você recebe um presente misterioso de um desconhecido. |
| 12-13   | Você é atingido por uma brisa mágica que aumenta sua velocidade temporariamente. |
| 14-15   | Você tem uma visão clara de algo que acontecerá no futuro. |
| 16-17   | Você é atingido por um feitiço de confusão, causando desorientação. |
| 18-19   | Seu equipamento é espalhado por toda a sala, mas não danificado. |
| 20      | Você é petrificado por um instante, como se estivesse em uma estátua. |

### Como Usar

Para usar esta tabela em um jogo de D&D, o Mestre do Jogo (DM) rola um d20 e consulta a linha correspondente para determinar o que acontece. O DM pode então descrever o resultado aos jogadores, adicionando sabor e emoção ao jogo.

Este é apenas um aspecto do sistema *Sortudo*, que pode ter regras adicionais ou mecânicas não abordadas aqui.
