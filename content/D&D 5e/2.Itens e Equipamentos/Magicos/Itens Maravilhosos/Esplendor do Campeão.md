# Esplendor do Campeão *(Champion's Splendor)*

**Fonte:** D&D Wiki
**Tipo:** Item Maravilhoso
**Dano:** —
**Propriedades:** 

Este pequeno diamante é dito para amplificar o poder de um verdadeiro campeão, servindo como uma relíquia suprema para a classe de [[Guerreiro|Fighter]]. Este item mágico escala com seu nível de classe; você não pode utilizá-lo se não estiver no requisito mínimo de nível daquela classe.

**Efeitos:**

*   **Esplendor Crítico**: A partir do 3º nível, o número necessário no d20 para realizar um golpe crítico (Critical Hit) é reduzido em 1.
*   **Esplendor Atleta**: A partir do 7º nível, ao usar o talento de **Atleta Extraordinário**, você adiciona seu bônus de proficiência completo aos rolos.
*   **Esplendor Estilo de Luta**: A partir do 10º nível, você adquire um **Estilo de Luta Adicional**.
*   **Esplendor Crítico (Dois)**: A partir do 15º nível, o número necessário no d20 para realizar um golpe crítico é reduzido em mais 1 (totalizando uma redução de 2).
*   **Esplendor Sobrevivente**: A partir do 18º nível, você pode dobrar seu modificador de **Constitution (Constituição)** ao usar o talento de **Sobrevivente**.
