# Luvas de Tina *(Tina's Gloves)*

**Fonte:** D&D Wiki  
**Tipo:** Item Maravilhoso  
**Dano:** -  
**Propriedades:**

As luvas são uma peça bem feita de couro branco, cada uma delas com seis botões internos e sempre impecavelmente limpas. Quando usadas, elas se ajustam perfeitamente à pele do usuário e são extremamente confortáveis. Qualquer dedo faltante é imperceptível enquanto o usuário está usando as luvas, pois os dedos das luvas "preenchem" o espaço e respondem ao usuário como se o dedo ainda estivesse lá. As luvas não fornecem nenhum feedback tátil adicional; você não consegue sentir nada com um dedo "preenchido".

Enquanto estiver usando as luvas, você pode usar sua ação para lançar o feitiço **Mãos Mágicas (Mage Hand)**.
