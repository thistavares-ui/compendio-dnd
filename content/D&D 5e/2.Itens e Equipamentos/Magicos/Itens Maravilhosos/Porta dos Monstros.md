# Porta dos Monstros *(Monster Door)*

**Fonte:** D&D Wiki  
**Tipo:** Item Maravilhoso  
**Dano:** -  
**Propriedades:**

Esta porta mágica serve como um portal para um reino habitado por uma variedade de monstros, de todos os tipos e tamanhos. Quando não está em uso, a porta diminui de tamanho, tornando-se quase imperceptível. Quando aberta, o portal se expande para uma área retangular de 0,9 x 1,5 m. É importante notar que os monstros não podem atravessar este portal, permitindo apenas a passagem de criaturas não-monstruosas.
