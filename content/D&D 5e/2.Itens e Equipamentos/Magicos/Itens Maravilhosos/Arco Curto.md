# Arco Curto *(Shortbow)*

**Fonte:** D&D Wiki  
**Tipo:** Arma Marcial a Distância  
**Dano:** 1d6 Perfurante  
**Propriedades:**  

O arco curto é uma arma simples usada para atirar setas. Ele é leve e fácil de usar, tornando-o uma escolha popular entre os arqueiros.

A munição do arco curto inclui:

*   **Munição:** (alcance 24/96)  
*   **Duas Mãos:** O arco curto requer duas mãos para ser usado.
