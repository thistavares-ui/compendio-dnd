# Mochila Maravilhosa *(Bag of Bags)*

**Fonte:** D&D Wiki
**Tipo:** Item Maravilhoso

A mochila parece ser uma mochila normal com uma algibeira fixa ao lado, mas com inspeção mágica você descobre que, por meio de uma Palavra de Comando, pode mudar o que é. Você pode transformar essa mochila em uma Bolsa Cabe Tudo, uma Mochila Prática ou um Buraco Portátil. Embora sempre que você mude o item, todos os conteúdos dentro são perdidos e podem apenas ser restaurados por meio de uma magia de desejo. Você também pode usar uma Palavra de Comando para mudar a algibeira em uma Bolsa de Componentes.

Quando encontrada, ela pode conter qualquer dos seguintes itens...

Contém:
- Um Saco de Dormir
- Uma Algibeira
- Uma Coleção de Histórias Lendárias
- Uma Caixa para Fogo
- Uma Lanterna Coberta com três pints (1,4 L) de óleo
- Um Kit de Refeição
- Uma Tenda
- Rações suficientes para sete dias
- Uma Sacola
- Um Cantil
- Uma Pedra de Amolar
