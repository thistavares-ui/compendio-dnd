# Dados de Dimensão Reduzida *(Dimensionality Reduction Dice)*

**Fonte:** D&D Wiki
**Tipo:** Item Maravilhoso (Pulseira)

Uma pulseira triangular composta inteiramente por dados d6. Os dados são de um negro profundo, com pontos em ouro reluzente. Não importa o ângulo ou a perspectiva sob a qual você os observe, cada dado sempre exibirá o número "1".

### Efeito da Dimensão Reduzida

Enquanto estiver usando esse item, todas as suas jogadas de dados sofrerão uma transformação dimensional. O número de dados lançados será dobrado, mas o valor máximo de cada dado será reduzido pela metade. Se essa divisão resultar em um número fracionário, ele será arredondado para baixo. 

*Por exemplo: uma jogada de dano de 1d12 se torna 2d6; uma jogada de 2d6 se transforma em 4d3; e uma jogada de 4d3 se converte em 8d1.*
