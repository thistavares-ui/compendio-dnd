# Aríete Arcano *(Aries Arcana)*

**Fonte:** D&D Wiki  
**Tipo:** Item Maravilhoso  

O Aríete Arcano é um item maravilhoso portável, com a aparência de um grande bighorn de adamantina, exceto pelas cornos de prata afixados ao final. Se examinado com o [[Categoria:Único|Detetar Magia]], este item tem uma aura de Transmutação Usar Magia. Seu peso é aumentado em 2,3 kg.

Este item atua como um aríete portátil, com seu bônus para testes de Força (Strength) para quebrar ou abrir portas aumentados. O aumento do bônus é determinado pela raridade do Aríete Arcano. Se tocar ou abrir uma porta desencadear uma armadilha mágica, como um Glifo de Proteção, quem fez o teste de Força (Strength) com este item adiciona o mesmo bônus a qualquer teste de atributo ou salvaguarda contra a armadilha.

Além disso, se o Aríete Arcano for usado para abrir uma porta selada pela magia Tranca Arcana, o item automaticamente lança Arrombar sobre a Tranca Arcana. Uma vez utilizado, essa propriedade do ram não pode ser usada novamente até o próximo amanhecer.
