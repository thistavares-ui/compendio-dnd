# Marbel de Armazenamento de Líquido *(Marble of Liquid Storage)*

**Fonte:** D&D Wiki  
**Tipo:** Item Maravilhoso  
**Dano:** -  
**Propriedades:**

Este item mágico, feito de vidro, pode conter até 1 barril (cerca de 150 litros) de qualquer líquido frio. Para armazenar o líquido dentro dele, basta jogá-lo no líquido desejado. Para liberar o conteúdo, você pode espremer o marbel para uma liberação lenta ou quebrá-lo para um jato abundante.
