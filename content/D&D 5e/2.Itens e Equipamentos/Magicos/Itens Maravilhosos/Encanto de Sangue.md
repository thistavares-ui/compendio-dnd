# Encanto de Sangue *(Bleed Charm)*

**Fonte:** D&D Wiki  
**Tipo:** Item Maravilhoso  
**Dano:** -  
**Propriedades:**

Este pedaço de fruta petrificada, esculpido para se assemelhar a um coração, está coberto com estacas de ferro. Enquante você estiver carregando este encanto, outras criaturas podem realizar testes de Sabedoria (Medicina) para estabilizá-lo quando você estiver com 0 Pontos de Vida como uma Ação Bônus. Se elas fizerem isso, podem rolar um d4 e adicionar o resultado ao teste.
