# Gêiser de Ocre *(Jarred Orchre Jelly)*

**Fonte:** D&D Wiki  
**Tipo:** Item Maravilhoso (Symbiote)  
**Dano:** -  
**Propriedades:**

O item é um jarro médio, cheio até a borda com um líquido amarelo espesso. Quando o jarro é aberto, a gosma imediatamente agarra a mão do jogador e começa a se mover para cobrir todo o corpo, processo que leva 1 rodada completa para ser concluído.

Quando o corpo está completamente coberto, a gosma se infiltra através da pele, formando um vínculo com o jogador. Este vínculo concede a habilidade **Spider Climb (Escalada de Aranha)**, permitindo ao jogador escalar superfícies difíceis, inclusive teto, sem necessidade de realizar um **Athletics (Atletismo)** check. Essa habilidade não pode ser usada se o jogador estiver segurando armas ou escudo, ou se estiver usando armaduras pesadas.

Para desfazer o vínculo, o jogador deve consumir uma teia de aranha, quebrando os laços do símbiote com ela e liberando-o através das fezes.
