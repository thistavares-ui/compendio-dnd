# Cabo das Trevas *(Dark Hilt)*

**Fonte:** D&D Wiki
**Tipo:** Item Maravilhoso (Raro)

Um simples cabo de espada que parece absorver a escuridão ao seu redor, o cabo cinza-púrpura crepuscular é, para o observador casual, completamente inexpressivo. 

Este item é um cabo de espada com a propriedade de Usar Magia. Enquanto segura o cabo, você pode usar uma Ação Bônus para fazer surgir uma lâmina de sombra pura ou dissipá-la no ar, como se estivesse usando o feitiço [[Categoria:Único|Lâmina Lúgubre]].
