# Jabuti Cartucho do Espaço Aberto *(Tortoise Shell of Open Space)*

**Fonte:** D&D Wiki  
**Tipo:** Objeto Maravilhoso  
**Dano:**  
**Propriedades:**

Este cartucho, com 45 cm de diâmetro, possui um cristal embutido em seu ápice que parece mostrar uma sala quando observado através dele.  

**Criação do Semiplano.**

Você pode usar uma ação para lançar o feitiço **Semiplano (Plane Shift)**, mas em vez de uma porta aparecer, todas as criaturas dispostas a tocar no cartucho são transportadas para o **Semiplano (Plane)**, e ele sempre abre para o mesmo **Semiplano (Plane)**.  

Uma vez usado dessa forma, este item não pode fazê-lo novamente até o próximo **Alvorecer (Dawn)**.
