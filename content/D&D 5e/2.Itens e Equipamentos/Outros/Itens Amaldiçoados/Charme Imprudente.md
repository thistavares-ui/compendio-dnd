# Charme Imprudente *(Reckless Charm)*

**Fonte:** D&D Wiki  
**Tipo:** Item Maravilhoso  

Este ídolo de pedra representa o rosto de um monstro com presas afiadas.  

Enquanto você estiver usando este item, seus ataques têm vantagem.  

**Maldição.** Enquanto estiver usando este item, os ataques contra você também têm vantagem.
